# Contact catalogue thumbnails

Run `node .contact-thumbnails/generate.cjs` from the frontend directory with Playwright Chromium installed. Captures all nine real Contact components in light and dark, using complete example contact data and the neutral architectural SVG. Output is 1000px-wide WebP at its natural aspect ratio. Regenerate after design changes. No AI-generated mockups, account data or live iframe previews are used in the catalogue.
