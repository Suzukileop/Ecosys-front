# FAQ catalogue screenshots

Run `node .faq-thumbnails/generate.cjs` from frontend with Playwright Chromium installed. Captures the nine actual FAQ components with the same five example questions and shared real header, reduced motion and a light palette. The first question is expanded where available to demonstrate the design. WebP images keep their natural aspect ratio and are 1000px wide. Regenerate after design changes. No iframe is used by the catalogue.
